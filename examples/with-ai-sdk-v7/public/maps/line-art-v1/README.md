# 栖霞山地图线描素材

本目录保留网页正在使用的6张透明PNG：3款山体（mountain-01～03，1200×600）及3款山脊（ridge-01～03，800×300）。素材依据用户提供的导览图线描风格使用内置 imagegen 生成，随后按交付尺寸导出，保留透明通道。完整生成提示词见 manifest.json。

山体与山脊按用户两次截图中的11个红圈接入“赏秋手绘”模式，配置见 lib/qixia-mountain-decorations.json。插画为装饰，不代表实测山峰、地形或植被。湖泊另以矢量波纹绘制，不依赖本目录图片。

未使用的树丛、小树图集、峭壁、云雾、水波、草地与总览图已从项目移除，不随本次提交。原15张素材的完整交付包仍保存在仓库外的“栖霞山线描地图素材-v1.zip”。

山脊并非严格像素无缝纹理。ridge-01、02拼接时建议端点对齐并重叠8～16像素；ridge-03两端有留白，建议重叠16～24像素。当前地图分别放置素材，未作连续平铺。
