# 高德地图配置与验收

项目位置：E:\github\枫客松\examples\with-ai-sdk-v7。

## 账号与 Key

1. 登录 https://console.amap.com/ ，按控制台要求完成开发者认证。
2. 应用管理 → 我的应用 → 创建新应用，名称可填“枫客松”。
3. 添加 Key，平台选择“Web 端（JS API）”，保存该 Key 和与它对应的安全密钥。
4. 再添加一个 Key，平台选择“Web 服务”，供后端高德 MCP 使用。不要将两类 Key 混用。
5. 编辑同目录的 .env.local，保留原有模型配置，填写以下三项：

~~~dotenv
AMAP_JS_API_KEY=你的Web端JS_API_Key
AMAP_JS_SECURITY_CODE=该JS_Key对应的安全密钥
AMAP_WEB_SERVICE_KEY=你的Web服务Key
~~~

真实密钥不提交版本库，不粘贴到聊天或截图。JS Key 需要送到浏览器以加载地图，可在高德控制台配置允许的访问域名；部署后的实际域名也应加入。服务 Key 和安全密钥只放服务端。对 Web 服务设置 IP 限制时，使用服务器对外出口 IP，不能填写游客手机 IP。控制台限制规则以账号界面为准。

保存配置后重启开发服务；开发模式通常也会自动重载环境文件。通过 /api/amap/config 可以查看是否配置完成，只返回公开 JS Key 和布尔状态，不返回服务 Key 或安全密钥。

## 首版功能

- 高德 JS API 2.0 真实底图，初始显示栖霞山。固定的栖霞山 WGS-84 参考点通过官方接口转换为 GCJ-02 后初始化，不复用南京市中心坐标。
- 搜索栖霞山参考点周边3.5公里内的景点、厕所、餐饮或其他关键词；结果来自高德，地图标记和列表可选中同一地点。
- 选中地点后点击“询问助手”，发送该公共地点的信息，聊天框自动展开。手动选点不代表用户已到达。
- 点击“开始定位”后才请求授权。浏览器持续定位的 WGS-84 坐标通过高德转换为 GCJ-02，显示定位点、误差圈和数据新鲜程度；停止时清除监听和图层，不保存轨迹。
- 用户定位仅供高德地图和主动点击的步行路线查询使用，不自动发送给语言模型。地图坐标转换会使用高德服务。
- 位置超过30秒或误差半径大于50米时，不用于新步行路线查询。小于50米也不代表已匹配到山路，不能据此判断游客位于哪条岔路。
- 步行路线查询采用高德道路数据，查询失败明确提示；不根据直线距离编造山路路线或步行时间。
- 后端通过官方 @ai-sdk/mcp 客户端发现高德工具，仅开放搜索、地点详情、坐标地址、距离与步行路线查询。工具名前缀为 amap_。MCP 不可用时，普通聊天仍可继续。
- 天气组件与接口保持原实现，收在地图右上角的天气浮层，供和风天气开发独立替换。

## 安全代理

浏览器将 serviceHost 设为同源 /_AMapService，服务端按固定接口白名单转发并附加安全密钥。Next.js 对下划线目录视为私有目录，因此源目录使用 app/%5FAMapService/[...path]。SDK 使用 JSONP 时需返回脚本 MIME 类型，并校验回调函数名称。

MCP 连接地址固定为官方 https://mcp.amap.com/mcp ，不接受用户传入服务器地址。底层配额和计费按高德控制台核对；模型 token 费用单独计算。

## 真机验收

1. 桌面打开 http://localhost:3000 ，确认真实底图、景点检索、选点和聊天。
2. 手机使用 HTTPS 地址访问；直接访问开发机的 http://192.168.x.x 不具备安全定位上下文。
3. 允许定位后检查误差半径，分别在开阔地、树荫和岔路测试。拒绝权限时应继续支持手动选点。
4. 切后台或锁屏后，网页可能停止更新；恢复前台需等新位置，不承诺后台持续定位。
5. 测试停止定位、网络失败、地图权限或配置错误，以及无可用步行路线时的提示。

已接入前台附近景点自动提示，不提供步道轨迹纠偏或后台轨迹记录。开启定位后默认启用，可独立关闭。景点分类查询最多载入50个高德景点作为本地触发候选，切换厕所、餐饮等搜索不会替换候选景点。候选范围与当前载入量会在页面标明，不代表覆盖景区全部景点。

自动提示要求：位置新鲜度30秒内、误差半径不超过30米，且距离加误差半径不超过60米；至少两次不同时间的位置、停留确认10秒后提示。多个景点在误差范围内难以区分时要求手动选点。离开需距离减误差超过110米、至少两次位置确认5秒，且同一景点10分钟内不再次提示。定位停止、质量差或页面切后台时取消待触发计时；恢复前台后只处理新的定位。

这些阈值是原型默认值，仍需山中真机测试和景点位置核实。弹卡展示已载入的真实高德地点信息，不自动上传精确定位或调用模型；游客点选询问时才发送公共地点信息。

官方说明：[JS API 安全配置](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)、[MCP 创建应用和 Key](https://lbs.amap.com/api/mcp-server/create-project-and-key)、[MCP 快速接入](https://lbs.amap.com/api/mcp-server/gettingstarted)。

## 定位超时排查

定位由浏览器 Geolocation 提供，先获得 WGS-84 位置，再交给高德转换。定位超时（浏览器错误码3）表示在15秒内没有取得位置，不等于地图 Key 或 MCP 出错。网页不能保证桌面内置预览具有可用的定位服务。之前的浏览器模拟行走测试验证功能逻辑，不代表已验证本机或手机的真实定位能力。

权限拒绝或首次定位超时、不可用时，页面会清除本次位置监听、旧位置和待触发弹卡，并显示“重新定位”及权限排查步骤，不再无限显示“等待新位置”。已定位成功后的短暂更新中断不会停止持续定位，但会取消待触发弹卡并暂停提示；新位置返回后恢复。Windows 可检查“设置 → 隐私和安全性 → 位置”，并在独立 Edge 浏览器给当前站点位置权限后对照测试。手机测试需系统定位、浏览器权限和 HTTPS。

## 定位成功但偏差较大

浏览器位置是设备和浏览器提供的估计，enableHighAccuracy 只是高精度请求，不能保证使用卫星定位，也不等同于手机高德 App 的定位结果。网页显示浏览器报告的误差半径和时间；大于50米的结果标为粗略定位，使用不同颜色的估计中心与范围，按误差半径调整首次地图视野，禁止景点自动触发和步行路线。之后第一次取得可用精度的位置时再调整视野。自动触发另有30米的更严格要求。

误差半径是数据源报告的估计，不是现场校验结果。正式验收应在同一部手机、同一位置，对照网页与地图 App 结果；如网页误差仍大，需要评估浏览器定位服务、系统精确位置权限和原生定位方案，不得通过修改坐标把定位点强行移到游客描述的位置。
