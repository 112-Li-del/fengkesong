# 栖霞山局部三维地形：已停用的试验

当前页面已恢复为平面地图，不再加载本试验的引擎和高程资源。以下保留试验说明，供后续参考。

试验仅处理局部真实高程、素色山体、景点标签和步行路线贴山。
试验曾默认开启立体视图，可切换为平面。山体只覆盖展示范围，外围高德底图保持原样。
展示范围不是景区官方边界；边缘约 8% 范围做高度渐隐以接平面；低于约 16 米的区域不着色，16–40 米渐显以保留平原与水面底图，不能用它测量地形。

## 数据与版本
- public/terrain/qixia.json：WGS84 范围 [118.945, 32.143, 118.984, 32.179]，97×97 采样。
- 来源：https://registry.opendata.aws/terrain-tiles/ ，Terrarium z13 瓦片。
- 中国区域的全球 SRTM / GMTED 地形数据 courtesy USGS；完整来源与许可：
  https://github.com/tilezen/joerd/blob/master/docs/attribution.md
- 采集日期、瓦片 URL 与 SHA256 保存在 JSON。数据不是实时测绘，也不表达台阶和细窄步道。
- three-r142.min.js 来自 npm three@0.142.0，与高德官方 GL 图层示例版本一致，
  原始 MIT 许可保存在 public/vendor/three-LICENSE.txt。当前不升级地图 SDK。
- 本地提供三维引擎和裁剪数据，游客浏览不需要访问 AWS/CDN。
- 不包含卫星影像、未授权第三方手绘图或实时红叶数据。

## 重新生成
准备 Python 与 Pillow 后，在 app 目录运行：
python scripts/prepare-qixia-terrain.py
这是可选的数据维护脚本，不参与网站构建；只下载覆盖展示范围的少量公开瓦片。

## 坐标与渲染
高程按 WGS84 采样，每个网格顶点转换为 GCJ-02，再通过高德 customCoords 转地图局部坐标。
不能用单个锚点平移整个网格。景点和路径来自高德，反算 WGS84 后采样地形高度。
默认高度增强 1.3 倍，可切真实比例或 1.6 倍；界面明确标注。
官方参考：https://lbs.amap.com/demo/javascript-api-v2/example/selflayer/glcustom-layer

## 验证与边界
应对比景区入口、栖霞寺、山峰等多个公开 POI 的水平位置；这只能检查地理对齐，不能证明高程为实测。
地图旋转时检查景点标签、路线贴合与区域外底图，手机检查 WebGL 和帧率。
标记作为可点击的屏幕标签展示，不作精确遮挡判断；普通高德底图文字仍在地平面，不代表山上高度。
GPS 精度限制不因三维地形改善。定位点/精度圈仍为原生平面覆盖物；山地定位高度适配留待后续。
真实设备性能和现场位置仍需实机验收。加载失败时保留普通地图，并支持重试。

后续：官方范围边界、景点建筑/手绘素材、林区色块、等高线，以及实地核验步道。
